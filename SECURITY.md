# Security and Sensitive Data

Do not add API keys, tokens, credentials, private URLs, personal information,
un-anonymized field data, ethics-review materials, institutional internal
documents, or confidential research records to this repository.

The checked-in prototype uses synthetic fixtures and does not provide a
privacy filter or redaction system. Users must review any data before placing
it in a local working copy or sending generated context to an external
service.

Security reporting instructions will be added if a supported public reporting
channel is established.
